### [HyperDB v0.11](https://hyperdb.will-be-done.app/)
HyperDB is a reactive, local-first database for TypeScript. You define typed schemas, selectors, and actions once and run them in the browser and on the server; only the storage driver changes (in-memory, IndexedDB, or SQLite). Every index is a B-tree, selectors name the index they read, and a write re-runs only the selectors whose scanned ranges it touched. This release adds `uncachedTables` to `HybridDB` for tables that should always be read from persistent storage.
